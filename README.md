# VBAレクチャー教材 - 清掃管理マクロで学ぶExcel VBA

## 概要
社内の事務職員向けに、実際に業務で使用している清掃管理マクロを題材としたVBA教材です。
全8レッスンで、VBAの基礎から実務レベルのマクロが読み書きできるようになることを目指します。

## 対象者
- Excelの基本操作はできるがVBAは未経験の方
- 業務で使っているマクロの仕組みを理解したい方

## 教材の使い方
1. `lessons/` フォルダ内のレッスンを01から順番に進めてください
2. 各レッスンの `lesson.md` を読み、`sample.bas` のコードをExcel VBEにコピーして実行してください
3. `macros/` フォルダには実務で使用しているマクロの参考コードが入っています

## カリキュラム

| レッスン | テーマ | 実務マクロとの関連 |
|---|---|---|
| 01 | VBA入門 | MsgBox、Sub構造 |
| 02 | 変数とセル操作 | Range/Cellsでの読み書き |
| 03 | 条件分岐と色付け | S→青、D→ピンクの色付け |
| 04 | 繰り返し処理 | 全行走査の一括処理 |
| 05 | ワークブック・シート操作 | ファイル選択・オープン |
| 06 | 文字列操作 | Mid$, InStrでのS/D判定 |
| 07 | データ転記と集計 | フロア別D/S集計 |
| 08 | 実践：統計シート作成 | 作業時間計算の自動生成 |

## 既存マクロ（参考コード）
- `macros/01_指示書色付け転記.bas` — 清掃指示書の色付けとフロア別転記
- `macros/02_統計集計.bas` — 清掃確認書の統計集計と作業時間計算

## 所要時間
各レッスン 30分〜1時間程度（全体で約6〜8時間）
