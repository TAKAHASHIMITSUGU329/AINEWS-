エグゼクティブサマリ: 前回宿題と本日の回答

前回MTGでの高橋担当の宿題は、大きく2つです。追加メールで返信した内容を踏まえ、本日は「初期MVPはKuroco + Cloudflareで成立する範囲に絞る」方向で回答します。

宿題1Kurocoでどこまでやるか

問い: Kuroco単独で有料アプリまで完結できるのか。フロント/バックエンドはどう分けるべきか。
回答: 初期MVPはKuroco + Cloudflareで軽量に開始する案が現実的です。Kurocoは会員管理・CMS・無料/有料の出し分け、Cloudflare Pagesはフロント表示、Cloudflare Workersは軽量API・Gemini/Search APIのサーバー側実行を担当します。
  • Kuroco: ログイン、会員ランク、記事CMS、表示制御
  • Cloudflare Pages: フロント画面、静的ページ、会員向けUI
  • Cloudflare Workers: Gemini/Search API実行、簡易的な利用回数管理
  • FastAPI: PDF生成、重いバッチ処理、複雑なクォータ管理が必要になった段階で追加

宿題2AI課金が青天井にならない方程式

問い: 有料サービスでAI/API利用料が膨らみ続けないよう、どう料金設計・利用制限するか。
回答: 使い放題にせず、プランごとにAI検索回数、PDF生成回数、SCS診断回数の月間上限を置きます。原価は「利用回数 x 1回あたりAPI原価」で管理し、月額料金が上限原価を上回るように設計します。
  • 月間API原価 = 検索回数 x 検索原価 + PDF回数 x PDF原価 + 診断回数 x 診断原価 + 固定費按分
  • 月額料金 >= 月間API原価 + サポート原価 + 利益
  • 上限到達時は翌月リセット、または追加購入にする
水野さんへの一言回答: 「初期MVPはKuroco + Cloudflareで軽量に始め、重い処理が出たらFastAPIを追加します。無料は静的、有料は動的AI機能。課金は月間クォータ制で青天井を防ぎます。」

結論サマリ

無料領域

AIを動かさないもの

週次メール、静的なAIニュース、固定チェックリスト、SCS制度の解説記事は無料で提供する。目的は集客と信頼形成。

有料領域

AIと検索APIを動かすもの

期間指定検索、キーワード検索、PDFレポート生成、SCS診断の個別レポートは従量課金が発生するため有料会員向けにする。

技術構成

Kuroco + Cloudflare

Kurocoはログイン、会員ランク、記事CMS、表示制御を担当。Cloudflare Pagesで表示し、Workersで軽量APIとサーバー側API実行を行う。

提案: 初期MVPは「Kuroco会員サイト + Cloudflare Pages + Cloudflare Workers」で始める。PDF生成や重い診断処理が必要になった段階でFastAPIを追加する。

AI利用は、主に「Google Search / Gemini Grounding」「Gemini要約」「PDF生成時のエグゼクティブサマリー」でコストが発生します。料金は変更されるため、下記は2026年6月時点の公開価格をもとにした概算です。

1回あたりコスト試算

厳密な原価は実行時の検索回数、記事数、トークン量で変わります。まずは月額プランを設計するため、保守的に「1検索=数円〜十数円」「PDF生成=数十円」を上限目安として置きます。

宿題2: Kuroco + Cloudflareでできること / FastAPI追加が必要なこと

機能KurocoCloudflareFastAPI追加判断
会員登録・ログイン可能不要不要Kuroco担当
無料/有料コンテンツの出し分け可能補助可能不要Kuroco担当
記事CMS・ニュースページ管理可能表示を担当不要Kuroco + Pages
フロント画面表示可能Pagesが得意不要Cloudflare Pages推奨
Gemini API実行非推奨Workersで可能原則不要APIキーをWorkers側に保持

PDF生成難しい軽量PDFなら検討、重いPDFは不向き必要拡張段階でFastAPI

メール配信限定的Webhook/API連携可能不要Resend連携
結論: Kurocoのコンテンツ内にAI APIキーを埋め込む構成は避けます。初期MVPではWorkersでサーバー側実行し、重い処理が出てきた段階でFastAPIを追加します。

推奨アーキテクチャ

1. ユーザー

メールや検索からKuroco上のAIニュースページへアクセス。

2. Kuroco

ログイン、会員ランク、無料/有料表示を制御。

3. Cloudflare Pages

検索フォーム、期間指定、会員向けUIを表示。

4. Workers

軽量API、APIキー保護、簡易クォータ、Gemini/Search実行。

5. 拡張バックエンド

PDF生成や重い診断が必要になったらFastAPIを追加。
