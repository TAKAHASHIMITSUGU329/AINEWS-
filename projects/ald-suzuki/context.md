   - 「AmouRis AIコーチ」のGemを作成しテスト済み
   - AmouRisのHP情報などを教師データに投入 → 親和性が良好

   - **MOSH（モッシュ）**: クリエイター型ツール、動画販売に最適、初期フェーズ向け、コスト低い → 推奨

   - **OneStream（ワンストリーム）**: 同上 → コストが高い
   - 結論: 国内ツール推奨、海外展開予定なし、MOSHでスモールスタート
   - ただし動画学習システム構築は先送り → まずVimeo等で動画コンテンツを蓄積

5. **Notion → 解約方針**
   - 月額4,000円の固定費
   - Google Docsで共有すれば十分、今すぐ大活躍するシーンが想像しにくい
   - 鈴木社長も同意「固定費かけてやる必要ないのでは」

6. **データストレージアーキテクチャ**
   - Google Drive（現在2TB契約）を当面使用
   - **Google Cloud Storage** を推奨（S3ではなくGoogle生態系で統一）
   - BigQuery: 現時点では不要（数百人規模までは過剰）、数万件以上のデータで必要になる
   - Looker Studioでの可視化は将来的に検討

     - **NotebookLM**: 教師データの収集・管理（知識リポジトリ）
     - **Gemini Gem**: AIインターフェース（カスタム指示 + NotebookLM知識）

8. **クライアント向けAIワーク構想**

### 重要な意思決定・方針
- **Claude Code への移行**: 両者ともメインAIツールとしてClaude Codeを採用

- **AIは「補完」であり「代替」ではない**: コーチの人間的サポートが軸（AI疲れ対策）
- **AIは黒子に徹する**: マーケ上、AIを前面に出すのは逆効果（広告疲れ・AI疲れトレンド）
- **OpusAI解約 → Gemini Gem → Claude Code**: ツール変遷が激しい
- **LINE Bot → 一時停止**: 商材リデザインが優先（2/23決定）
- **Notionの解約**: Google Docsで代替、固定費削減
