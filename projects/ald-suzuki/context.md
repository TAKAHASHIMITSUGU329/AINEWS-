#### 議題と内容

1. **コーチング事業の方針**

   - 現在の予算制約により、より手頃な代替案を優先する方針転換に合意

2. **「自給家族」農業プロジェクト**

   - 農村と都市部のマッチングを通じた米作り継続の重要性
   - AIが農村の自治・コミュニティ構築をサポートする可能性を検討

3. **AI活用戦略**
   - まずはChatGPT・Geminiなどの無料版AIを試す方針
   - 実績を積み上げながら独自AIを開発していく段階的アプローチ
   - コスト・サーバー費用の懸念あり
   - Geminiがスプレッドシート連携・日本語処理で優位と評価

4. **データ管理・ストレージ**
   - 面談やコーチングセッションの動画データ保存方法
   - 現時点ではGoogle Drive等の手軽なストレージで十分
   - 将来的にAI解析の研究材料として活用予定

5. **プラットフォーム・ツール検討**
   - コーチング面談: Zoom推奨（Google Meetのラグ問題）
   - 情報共有: Notion / Google Docs / Google Spreadsheet
   - オンライン学習サービスの競合が激化、2社程度を検討中

   - **目的**: 350,000円の高額コーチング商品の契約獲得
   - LINEでAIボットを展開する戦略を検討
   - GeminiとLINEの連携でAIボット作成の可能性
   - Lステップとの連携・API検証が必要
   - AIボットと人間サポートの切り替えバランスが重要

3. **マーケティング戦略**
   - 認定コーチごとの閲覧範囲を厳密制御（ノートブックルーム管理）
   - 競合がプロフェッショナル系から若い女性層にシフト

3. **オンラインスクール/Eラーニング** - 検討段階

### 重要な注意事項
- AIの前面押し出しには慎重に（AI疲れ・反動のトレンド）
- AIボットは人間サポートの「補完」であり「代替」ではない
- 予算制約があるため、段階的な導入が必須
- 認定コーチへの情報アクセス権限は厳密に管理
