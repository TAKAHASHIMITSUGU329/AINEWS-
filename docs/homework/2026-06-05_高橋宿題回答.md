# 2026/06/05 向け 高橋宿題回答

作成日: 2026年6月4日  
対象: 2026年5月15日 MTG の高橋担当宿題  
参照: 2026.05.15 議事録 / 文字起こし

## 1. 宿題の理解

前回MTGで高橋側に求められた宿題は、以下の4点です。

1. **無料会員向けサービスの構築方法を調査する**
   - 無料配信、AIニュースサイトをどう作るか
   - Kuroco を活用できるか
   - 必要なら Resend など別メール配信システムを使うか

2. **3つのボックスに入れるサービス案を具体化する**
   - 完全無料コンテンツ
   - 有料サブスク
   - 有料ワンショットサービス

3. **SCS評価制度に対応する新規アプリ・サービス案を出す**
   - SCS評価制度を事業機会として捉え、診断・支援・証明・運用に結びつくアプリ案を出す

4. **高橋自身が提供できるワンショットサービス案を整理する**
   - 開発、会員サイト構築、資料生成、業務自動化などを有料ワンショットの部屋に置けるか検討する

## 2. 結論

高橋案としては、**「Kurocoを会員・CMSの中核に置き、無料情報配信はKuroco + Resend、アプリ群は静的HTML/軽量Webアプリで分離するハイブリッド構成」**を推奨します。

サービス構造は、前回MTGで整理された **3つのボックス** をそのまま採用します。

| ボックス | 役割 | 主な収益性 | 高橋案 |
|---|---|---:|---|
| 完全無料 | 集客・信頼形成・リスク喚起 | 低 | AIニュース、週次メール、情報漏洩チェック、簡易SCSセルフチェック |
| 有料サブスク | 継続収益・日常利用 | 中 | EDR、7ツール、詳細ニュース、月次PDF、SCS対応度チェッカー |
| 有料ワンショット | 高単価・個別支援 | 高 | SCS支援、研修、ガイドライン作成、会員サイト/業務アプリ開発 |

特に重要なのは、無料コンテンツを「出し惜しみ」するのではなく、**無料情報でリスクを認識させ、有料サブスク・ワンショットへ自然に誘導すること**です。

## 4. 無料会員向けサービスの構築方法

### 4-1. 推奨構成

| 機能 | 推奨ツール | 理由 |
|---|---|---|
| 会員登録・ログイン | Kuroco | 既に検証済み。無料/有料/管理者などのティア制御ができる |
| ニュース記事CMS | Kuroco | コンテンツ管理とAPI配信に向く |
| 静的サイト表示 | Vercel / Netlify / 静的HTML | 低コストで表示が速い。Kuroco APIと相性が良い |
| メール配信 | Resend 併用推奨 | 開発者向けでAPI連携しやすい。無料枠から始めやすい |
| AIニュース収集 | AiNEWS既存機能 | Gemini Search Grounding + 要約処理を既に実装済み |
| 月次PDF | AiNEWS既存機能 | 既存 `app/report.py` でレポート生成可能 |

### 4-2. Kurocoだけで完結させるか

**短期はKuroco中心で良い**です。  
ただし、メール配信や配信ログ、開封率、ステップメールのような運用まで考えると、Kuroco単体に寄せすぎるより、**メール配信はResend等の専用サービスを併用する**ほうが運用しやすいです。

### 4-3. 無料ニュース配信のMVP

最初のMVPは以下で十分です。

1. AiNEWSで週次ニュースを収集
2. Geminiで3行要約と対策アクションを生成
3. Kurocoに記事として登録
4. 無料会員向けページに一覧表示
5. Resendで週1回メール配信
6. 詳細分析・チェックリスト・PDFは有料導線にする

### 4-4. 無料コンテンツで出すべきもの

| 無料で出すもの | 狙い |
|---|---|
| AIインシデントニュースのタイトル・3行要約 | 継続的に見に来る理由を作る |
| 週次メール「今週のAIリスク3選」 | 接点を維持する |
| 情報漏洩チェックへの導線 | 危機感を作る |
| SCS簡易チェック 5問 | ワンショット支援への入口 |
| 研修動画の一部 | 有料研修の入口 |
| ガイドライン雛形のサンプル | 有料カスタマイズ支援の入口 |

### 4-5. Resendの仕様詳細

無料ニュース配信のメール基盤として、Resendは有力です。  
特に、**週次メール、登録完了メール、月次レポート通知、管理者向け通知**のような用途に向いています。

#### 料金・上限

| 項目 | Free | Pro | Scale |
|---|---:|---:|---:|
| 月額 | $0 | $20 | $90 |
| 月間メール数 | 3,000通 | 50,000通 | 100,000通 |
| 追加メール | なし | $0.90 / 1,000通 | $0.90 / 1,000通 |
| 1日送信上限 | 100通 | なし | なし |
| ドメイン数 | 1 | 10 | 1,000 |
| Webhookエンドポイント | 1 | 10 | 10 |
| データ保持 | 30日 | 30日 | 30日 |
| Automation Runs | 10,000/月 | 10,000/月 | 10,000/月 |

※ Resendの料金は変更される可能性があるため、導入時は公式価格表で再確認が必要です。

#### Marketing Email / Contacts

Resendには通常のTransactional Emailとは別に、Contactsを使ったMarketing Emailがあります。

| 項目 | 内容 |
|---|---|
| Contacts | メールアドレス単位の顧客リスト |
| Segments | Contactsを分類するグループ |
| Broadcasts | Contacts / Segmentsに送る一斉配信 |
| Unsubscribe | Broadcastsでは購読解除フローを自動処理 |
| Contact登録方法 | API、CSVアップロード、手動追加 |
| FreeのMarketing枠 | 1,000 contacts |

無料ニュース配信では、最初は **Contacts + Segments + Broadcasts** を使うのが自然です。  
例えば、以下のように分けられます。

| Segment | 用途 |
|---|---|
| free_members | 完全無料ニュース配信 |
| trial_members | 初月無料ユーザー |
| paid_members | 有料サブスクユーザー |
| one_shot_leads | ワンショット相談の見込み客 |

#### API・実装面

ResendはREST APIと公式SDKを提供しており、Python / Node.js などから送信できます。AiNEWSの場合は、以下の流れで実装できます。

1. AiNEWSが週次ニュースを収集・要約
2. 配信用HTML本文を生成
3. Resend APIで対象Segmentに配信
4. 配信結果・エラーをWebhookで受け取る
5. バウンスや購読解除を管理画面で確認

#### ドメイン認証

本番運用では、独自ドメインの認証が必須です。Resendでは、送信ドメインに対して以下を設定します。

| DNS設定 | 目的 |
|---|---|
| SPF | Resendがそのドメインから送信してよいことを示す |
| DKIM | メールが改ざんされていないことを証明する |
| DMARC | SPF/DKIMの結果に応じた受信側ポリシーを示す |

Resendはサブドメイン利用を推奨しています。例: `news.example.com` / `updates.example.com`。  
AiNEWSでも、メインドメインの評判を守るため、メール配信用サブドメインを分けるのが安全です。

#### 制限・注意点

| 注意点 | 内容 |
|---|---|
| Freeは1日100通まで | 100人を超える配信テストではProが必要 |
| API rate limit | デフォルトはチームあたり5 requests/sec |
| 429エラー | 日次/月次上限超過やAPI過多で発生 |
| データ保持 | Free/Pro/Scaleは30日 |
| Contacts上限 | Marketing配信はContacts枠に注意 |
| 配信品質 | SPF/DKIM/DMARC設定、送信頻度、件名品質が重要 |

#### AiNEWSでの推奨使い方

| フェーズ | 使い方 | プラン目安 |
|---|---|---|
| 検証 | 管理者・関係者10〜30人へ週次配信 | Free |
| 小規模MVP | 無料会員100〜500人へ週次配信 | Pro検討 |
| 本格運用 | 1,000人以上、Segment別配信、月次通知 | Pro以上 |
| 大量配信 | 数万人規模、送信評判管理、専用IP | Scale以上 |

高橋案としては、**最初はFreeで配信テストし、無料会員が100人を超えたらProに移行**するのが現実的です。

#### Kurocoとの役割分担

| 役割 | Kuroco | Resend |
|---|---|---|
| 会員登録・ログイン | ◎ | × |
| 会員ランク管理 | ◎ | △ |
| 記事CMS | ◎ | × |
| メール配信 | △ | ◎ |
| セグメント配信 | △ | ◎ |
| 購読解除 | △ | ◎ |
| 配信ログ | △ | ◎ |
| Webhook連携 | ○ | ◎ |

結論として、Kurocoは **会員・記事・権限制御**、Resendは **メール配信・購読解除・配信ログ** に分けるのが良いです。

## 5. Kuroco以外のサービス ベンチマーク

### 5-1. 結論

Kuroco以外にも選択肢はあります。今回の「無料ニュース配信 + 会員認証 + 有料サブスク + ワンショット導線」という用途では、候補は大きく4系統に分かれます。

| 系統 | 候補 | 評価 |
|---|---|---|
| 会員サイト特化 | Outseta / Memberstack | **最短で会員サイト化するなら有力** |
| 認証・DB基盤 | Supabase / Firebase | **開発自由度と低コストを重視するなら有力** |
| 認証特化 | Clerk / Auth0 / Amazon Cognito | **アプリ開発前提なら強いが、CMSは別途必要** |
| CMS特化 | microCMS / Contentful | **記事管理には強いが、会員・課金は別途必要** |

高橋案としては、短期MVPでは **Kuroco継続**、代替候補としては **Outseta** と **Supabase** を優先比較対象に置くのが現実的です。

### 5-2. 比較表

| サービス | 得意領域 | 会員認証 | CMS | 課金 | メール配信 | 今回の適合度 | コメント |
|---|---|---:|---:|---:|---:|---:|---|
| Kuroco | 日本製ヘッドレスCMS + 会員管理 | ◎ | ◎ | ○ | ○ | ◎ | 既に検証済み。日本語運用しやすい。従量課金の見積もり管理が論点 |
| Outseta | 会員サイト、CRM、課金、メール一体型 | ◎ | △ | ◎ | ◎ | ◎ | 「3つのボックス」を最短で実装しやすい。Founder $37/月、1,000 contacts、課金手数料あり |
| Memberstack | 会員制サイト、Stripe課金 | ◎ | △ | ◎ | △ | ○ | Webflow等との相性が良い。Basic $29/月、1,000 members、取引手数料あり |
| Supabase | Auth + DB + Edge Functions | ◎ | △ | △ | × | ◎ | 50,000 MAU無料枠が大きい。開発自由度が高い。CMS画面は別途作る必要あり |

| Clerk | 認証UI・B2B認証・課金連携 | ◎ | × | ○ | × | ○ | 認証UIが強く実装が速い。Hobbyは50,000 MRU、Proは月額課金 |
| Auth0 | エンタープライズ認証 | ◎ | × | × | × | △ | 認証は強いが、この案件にはやや重い。B2B/SSO重視なら候補 |

| microCMS | 日本製ヘッドレスCMS | × | ◎ | × | × | ○ | 記事CMSとしては有力。会員・課金はClerk等と組み合わせる |

### 5-3. 推奨順位

| 順位 | 構成 | 向いているケース |
|---:|---|---|
| 1 | **Kuroco + Resend + 静的HTML/軽量アプリ** | 既存検証を活かし、短期で無料ニュース配信を始める |
| 2 | **Outseta 単体 + 静的ページ** | 会員管理、課金、メール、CRMを一体で素早く作る |
| 3 | **Supabase + microCMS + Resend** | 将来的に独自アプリやSCS診断DBをしっかり作り込む |
| 4 | **Clerk + microCMS + Stripe/Resend** | 認証UIと課金導線をきれいに作りたい |
| 5 | **Firebase + microCMS/独自CMS** | Google系で低コストに始めたい |

### 5-4. 判断

現時点でKurocoをすぐ捨てる必要はありません。  
ただし、**「有料サブスク」「CRM」「メール」「ヘルプデスク」まで一体運用したいならOutseta**、**独自アプリを増やしていくならSupabase** が強いです。

次回MTGでの提案は以下が分かりやすいです。

> 短期はKuroco継続で無料配信MVPを作ります。並行して、会員・課金・メールを一体運用できるOutsetaと、独自アプリ開発に強いSupabaseを代替候補としてベンチマークします。
