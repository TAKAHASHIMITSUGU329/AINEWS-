# レッスン1: VBA入門 - はじめの一歩

## このレッスンで学ぶこと
- VBAとは何か
- VBE（Visual Basic Editor）の起動方法
- 最初のプログラムを書いて実行する

---

## 1. VBAとは？

VBA（Visual Basic for Applications）は、Excelに組み込まれたプログラミング言語です。
普段手作業でやっている操作を自動化できます。

**実務での活用例（私たちのマクロ）：**
- 清掃指示書の部屋に自動で色を付ける
- フロア別のデータを集計シートに自動転記する
- 作業時間を自動計算する

これらはすべてVBAで実現しています。

## 2. 開発タブの表示

VBAを使うには「開発」タブが必要です。表示されていない場合：

1. Excelを開く
2. **ファイル** → **オプション** → **リボンのユーザー設定**
3. 右側の一覧で **「開発」にチェック** を入れる
4. **OK** をクリック

## 3. VBE（Visual Basic Editor）の起動

VBEはVBAのコードを書く場所です。

**起動方法（どちらでもOK）：**
- 開発タブ → **Visual Basic** ボタンをクリック
- キーボードで **Alt + F11**

### VBEの画面構成
- **プロジェクトウィンドウ**（左上）: ブックやシートの一覧
- **コードウィンドウ**（右側）: ここにプログラムを書きます
- **イミディエイトウィンドウ**（下部）: 簡単なテスト用（Ctrl+Gで表示）

## 4. 標準モジュールの追加

コードを書く場所を作ります。

1. VBEのメニューで **挿入** → **標準モジュール**
2. 右側にコードウィンドウが開きます

## 5. 最初のプログラム

以下のコードをコードウィンドウにコピーして貼り付けてください：

```vba
Sub はじめてのマクロ()
    MsgBox "こんにちは！VBAの世界へようこそ！"
End Sub
```

### 実行方法
1. コード内にカーソルを置く
2. **F5キー** を押す（または ▶ 実行ボタン）
3. メッセージボックスが表示されます

### コードの解説
- `Sub はじめてのマクロ()` — プログラムの始まり。`Sub` は「サブルーチン（処理のまとまり）」の略
- `MsgBox "..."` — メッセージボックスを表示する命令
- `End Sub` — プログラムの終わり

> **実務マクロではここで使われています：**
> ```vba
> MsgBox "色付けと 4F～15F の転記が完了しました。", vbInformation
> ```
> マクロ1（指示書色付け転記）の最後で、処理完了を知らせるために使っています。

## 6. もう少し試してみよう

```vba
Sub あいさつ()
    MsgBox "本日の清掃作業を開始します！", vbInformation, "確認"
End Sub
```

- `vbInformation` — 情報アイコン（ℹ️）を表示
- `"確認"` — メッセージボックスのタイトル

他にも試してみましょう：
- `vbExclamation` — 警告アイコン（⚠️）
- `vbQuestion` — 質問アイコン（？）

## 7. Exit Sub について

処理を途中で終了したいときは `Exit Sub` を使います。

```vba
Sub 確認テスト()
    Dim answer As VbMsgBoxResult
    answer = MsgBox("続けますか？", vbYesNo)

    If answer = vbNo Then
        MsgBox "中止しました。"
        Exit Sub
    End If

    MsgBox "処理を続行します！"
End Sub
```

> **実務マクロではここで使われています：**
> ```vba
> If filePath = False Then Exit Sub
> ```
> ファイル選択をキャンセルしたとき、マクロを中止しています。

## まとめ
- VBAはExcelの操作を自動化するプログラミング言語
- VBEは **Alt+F11** で起動
- `Sub`〜`End Sub` がプログラムの基本構造
- `MsgBox` でメッセージを表示できる
